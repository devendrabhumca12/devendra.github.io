## 🚀 Getting Started

### Prerequisites
- Node.js 20+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/devendrabhumca12/devendra.github.io.git
cd devendra.github.io

# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Local Development
```bash
npm run dev
# Opens at http://localhost:5173
```

### Build & Deploy
```bash
npm run build
git add .
git commit -m "update: portfolio changes"
git push origin main
# Automatically deployed to GitHub Pages via GitHub Actions
```
